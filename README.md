# 排寒療法：頭涼腳暖（簡版）

## 核心
上涼下暖，頭涼腳暖。「風是百病之長，百病從寒起」。

## 每日做法
- **半身浴**：手胸以上露水，泡半小時（寒氣重可一個鐘）；冇條件就泡腳，泡完着襪
- **食**：細嚼慢嚥廿五分鐘以上；早餐六七分飽、中餐七八分、晚餐五六分
- **瞓覺**：熱水袋放腳踝腳底或肚臍；着衛生褲棉毛褲，被子蓋下半身

## 理念
靠身體自癒力排寒，唔使手術藥物。作者分享洗腎病人一年後腎功能恢復、三十年中耳炎患者聽力恢復嘅個案。

## 科學護欄
- **有據**：半身浴增強血流同代謝（基礎代謝每日多二百千卡）；規律冷水沖涼提升免疫球蛋白；冷啟動棕色脂肪改善血糖
- **薄弱**：冷水對情緒長期效果證據弱；運動後冰浴可能延慢肌肉修復
- **存疑**：「排寒治百病、唔使就醫」缺乏臨床驗證，單一個案唔等於因果
